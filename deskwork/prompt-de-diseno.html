01

El prompt · listo para copiar

Usa este bloque tal cual en una herramienta de IA que genere HTML, presentaciones o interfaces. Está diseñado para producir una página coherente con la marca DeskWork sin instrucciones adicionales.

Diseña una página web en HTML + CSS (un solo archivo, self-contained, sin frameworks externos salvo Google Fonts) para DeskWork, una plataforma SaaS B2B de gestión inteligente de soporte interno. Contexto del producto - DeskWork centraliza solicitudes, las prioriza automáticamente, mide tiempos y ayuda a las áreas internas a mejorar continuamente. - Caso piloto: Fundación TECHO-Chile (185 trabajadores, 11 regiones, una sola persona gestionando TI). - 5 niveles de usuario: 0=Soporte TI, 1=Director, 2=Jefatura, 3=Administrativo, 4=Voluntario. - Estados de ticket: ABIERTO, EN PROCESO, ESPERANDO USUARIO, ESCALADO, RESUELTO, CERRADO. - Prioridad calculada por el sistema (no por el usuario): P1/P2/P3/P4. Identidad visual - Color principal: #0d4f4a (DeskWork teal). Versión oscura: #0a3d39. Acento suave: #d9eae7. Acento vivo: #6ee7df. - Fondo principal: #fafaf7 (off-white cálido). Superficies: #ffffff. Bordes: #e9e3d6. Texto principal: #14171e. Texto secundario: #3a4256. Muted: #7c7a72. - Colores funcionales: crítico #b3331f, alto #c2410c, normal #a16207, bajo/resuelto #047857, info #1d4ed8. Cada uno con fondo pastel (mezcla 90% blanco + 10% color). - Tipografía: Outfit (sans, pesos 300-700) para todo el texto. JetBrains Mono para IDs, timers, datos numéricos y código. - Carga las fuentes desde Google Fonts. Reglas de diseño - Estética sobria, institucional, moderna. Nada futurista ni "AI-looking". Cero gradientes azul-morado. - Mucho espacio en blanco. max-width: 1200px para el contenido principal, padding generoso. - Cards con borde 1px sólido (var --line), radio 12-16px, sin sombras pesadas. - Sombras solo si elevan un componente: sm 0 1px 2px, md 0 4px 16px -2px, lg 0 12px 32px -4px. - Iconografía: Lucide (SVG inline, stroke 2, viewBox 24x24, currentColor). NUNCA emojis como iconos. - Diagramas con SVG inline o CSS grid. NUNCA ASCII art con caracteres de caja. - Estados con pills (chip pequeño con dot de color y texto), nunca con banners. - Botones primarios: fondo #0d4f4a, texto blanco, radio 10px, padding 12px 20px. - Botones secundarios: fondo blanco, borde #e9e3d6, texto #3a4256. - KPIs: número grande en JetBrains Mono, label pequeño en uppercase tracked (0.08em), sub en muted. - Gráficos de barras: barras horizontales con track #f0ebde, fill #0d4f4a, valor a la derecha en mono. - Tablas: header con fondo tenue, filas con borde inferior #e9e3d6, fuente sans 12-13px. - Mockups: topbar con tres dots estilo browser, URL en mono, opcional sidebar oscuro. - Animaciones: solo fade-in al entrar viewport, nunca parallax ni efectos llamativos. Jerarquía tipográfica - H1: 40-56px, peso 700, line-height 1.05, letter-spacing -0.025em. - H2: 28-36px, peso 600, line-height 1.1, letter-spacing -0.02em. - H3: 18-22px, peso 600. - Body: 14-16px, peso 400, line-height 1.55-1.6. - Eyebrow / microtexto: 11px, peso 500, letter-spacing 0.12em, uppercase, color #7c7a72. Lo que NUNCA debes hacer - Gradientes azul-morado, neón, sombras de glow. - Emojis como iconos. - ASCII art (┌─┐ │ ├─) para diagramas. - Tres tarjetas idénticas lado a lado. - border-l-4 (la barra lateral de color) como estilo principal. - h-screen en cada sección (rompe el scroll natural). - Arial, Roboto, Inter, Fraunces, fuentes del sistema. - Texto marketing: "seamless", "elevate", "transform", "empower", "next-gen". - Fotografías de personas genéricas con notebooks. Estructura esperada - Header sticky con logo + breadcrumb. - Barra de progreso superior (1-2px) que avanza con el scroll. - Secciones a pantalla completa (min-height: 100vh, no height). - Navegación interna o numerada. - Cierre con CTA y créditos. - Responsive: mobile < 768px, tablet 768-1024, desktop > 1024.
Cómo usar este prompt. Pégalo íntegro en una herramienta como Mavis, Claude, ChatGPT, v0, o cualquier generador de UI. Si necesitas algo más específico (por ejemplo "una página solo de pricing" o "un mockup de móvil"), añádelo como instrucción extra al final. El prompt base ya contiene todas las reglas de marca.

03

Variantes del prompt según entregable

El prompt principal es genérico. Estas son instrucciones extra para casos específicos.

Para una página web / dossier

"Genera una página de presentación scrolleable, con secciones numeradas. Cada sección ocupa al menos una pantalla (min-height: 100vh). Usa sticky nav superior y barra de progreso de scroll. Cierra con un CTA y un bloque de créditos."

Para un mockup de interfaz

"Genera el mockup visual de un producto SaaS dentro de un marco tipo navegador: topbar con 3 dots + URL monoespaciada + avatar de usuario. El mockup debe distinguir entre vista técnica (sidebar oscuro, fondo #14171e) y vista de usuario (sidebar claro o ausente, fondo blanco)."

Para una presentación para imprimir / PDF

"Genera una página optimizada para impresión: max-width 980px, sin animaciones de scroll, sin sticky nav, sin position fixed. Cada sección debe caber limpia en una página A4 vertical. El contraste debe ser alto para lectura en papel."

Para un dashboard de datos

"Genera un dashboard con: header de KPIs (4-5 métricas grandes con label y delta), gráfico principal (Chart.js con gridlines tenues rgba(0,0,0,0.04) y tipografía Outfit), tabla de detalle, y sección lateral con listas o breakdowns. No usar más de 2 colores de acento en todo el dashboard."

Para una ficha de marketing one-pager

"Genera una página de una sola pantalla (sin scroll) que comunique la propuesta de valor en menos de 10 segundos de lectura: titular grande, sub-beneficio, 3 bloques con icono + título + descripción, y un CTA final. Densidad alta pero no saturada."

04

Anti-patrones · lo que DeskWork prohíbe

Si una IA o un diseñador te entrega algo con estas características, no es DeskWork. Hay que rehacerlo.

Visuales prohibidos

  • Gradientes de azul a púrpura estilo "AI startup genérica".
  • Sombras de glow neón o efectos de blur exagerados.
  • Emojis (📊 ✅ 🚀 ⚡) usados como iconografía principal.
  • ASCII art con caracteres de caja (┌─┐ │ ├─) para diagramas.
  • Tres tarjetas idénticas lado a lado (3-equal-cards).
  • Barra lateral de color (border-l-4) como estilo principal de tarjetas.
  • Cada sección a pantalla completa forzada con h-screen.
  • Fotografías de personas genéricas con notebooks en la cabeza.
  • Fondos blancos puros #ffffff en áreas grandes (usar #fafaf7).
  • Exceso de iconos decorativos sin función.

Tipográficas prohibidas

  • Inter, Roboto, Arial, Fraunces, fuentes del sistema, sans-serif genérico.
  • Centrar todo el texto en hero (mejor left-aligned con max-width).
  • Encabezados en mayúscula sostenida (UPPERCASE largo en H1/H2).
  • Tracking abierto en cuerpo (solo en eyebrow / microtexto).
  • Justificar texto en párrafos.

De copywriting prohibidas

  • "Seamless", "elevate", "transform", "empower", "next-gen", "cutting-edge".
  • "Potenciado por IA" como claim principal (la IA llega después).
  • Adjetivos sin dato: "increíble", "revolucionario", "único".
  • Estadísticas de relleno ("+500% de crecimiento" sin contexto).
  • Promesas que DeskWork no puede cumplir como MVP.
